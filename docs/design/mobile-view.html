Mở bản chạy trực tiếp trên điện thoại

Trang link này không nối mạng ra ngoài được (nền tảng chặn mọi kết nối tới máy chủ khác), nên số liệu ở trên là ảnh chụp. Bản tick từng giây nằm trong file dashboard-standalone.html:

  1. Lưu file vào điện thoại — gửi qua Zalo/Telegram/Mail cho chính mình, hoặc bỏ vào iCloud Drive / Google Drive rồi tải về máy.
  2. iPhone: mở app Tệp → chạm file → chia sẻ → Mở trong Safari. Android: mở Files → chạm file → chọn Chrome.
  3. File tự nối thẳng Binance public API — không cần API key, không cần cài gì. Nhà mạng chặn Binance thì trang báo «Mất kết nối» chứ không bịa số.
  4. Muốn ai cũng mở được bằng link thật: đưa file lên host tĩnh (GitHub Pages, Netlify Drop, Cloudflare Pages) — nói tôi biết nếu anh muốn làm bước này.
