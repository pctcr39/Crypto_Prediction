Mở bản chạy trực tiếp trên điện thoại

Trang link này không nối mạng ra ngoài được (chính sách bảo mật của nền tảng chặn mọi kết nối tới máy chủ khác), nên số liệu ở trên là ảnh chụp. Bản tick từng giây nằm trong file dashboard-standalone.html:

  1. Lưu file vào điện thoại — gửi qua Zalo/Telegram/Mail cho chính mình, hoặc bỏ vào iCloud Drive / Google Drive rồi tải về máy.
  2. iPhone: mở app Tệp (Files) → chạm file → góc trên chọn chia sẻ → Mở trong Safari. Android: mở Files → chạm file → chọn Chrome.
  3. File tự nối thẳng Binance public API — không cần mạng riêng, không cần API key, không cần cài gì. Nếu nhà mạng chặn Binance thì trang sẽ báo «Mất kết nối» chứ không bịa số.
  4. Muốn ai cũng mở được bằng link thật: đưa file lên một chỗ host tĩnh (GitHub Pages, Netlify Drop, Cloudflare Pages). Nói tôi biết nếu anh muốn làm bước này.
